## ✨ Highlights

- Oversized **masked-reveal hero** with a parallax glow
- **Mix-blend nav** that inverts over sections
- Full-bleed **services marquee**
- Staggered work grid with hover reveal
- Manifesto section + oversized contact CTA

## 🧱 Tech stack

| Layer | Tech |
|-------|------|
| Framework | React 18 + Vite |
| Styling | Tailwind CSS |
| Motion | GSAP + Framer Motion |
| 3D | Three.js / React Three Fiber |
| Icons | Lucide |

## 🚀 Run locally

```bash
npm install
npm run dev
npm run build
```
