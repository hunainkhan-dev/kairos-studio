# Kairos — Creative Studio

Cinematic agency site concept. React + Vite + Tailwind + Framer Motion.

**Highlights:** oversized masked-reveal hero with a parallax glow, mix-blend nav, full-bleed services marquee, staggered work grid with hover reveal, manifesto section, and an oversized contact CTA.

## Run
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

Portfolio case study for **Hunain**. Client names and imagery are illustrative.
